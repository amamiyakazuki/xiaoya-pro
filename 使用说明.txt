小雅刷课助手 0.5.0（Chrome / Microsoft Edge 120 及以上）

安装
1. 将安装包完整解压到固定目录。
2. Chrome 打开 chrome://extensions/，Microsoft Edge 打开 edge://extensions/。
3. 启用“开发者模式”，点击“加载未打包的扩展程序”。
4. 选择解压后的 extension 文件夹。
5. 点击工具栏中的扩展图标打开侧栏。已登录的小雅页面可以在保存草稿后重开。

Chrome 与 Edge 复用同一份 extension 代码。使用 Edge 时在 Edge 内单独登录小雅。
包内附有当前浏览器的安装指引和 CHANGELOG.md。真实 Edge 平台流程尚未完成验证。

视频与课件队列
1. 点击工具栏的扩展图标打开侧边栏，查看待完成、已完成、已截止的任务。
   刷新需要开着一个已登录的小雅标签页；没有时显示上次的数据并提示打开小雅。
   点击任务跳转到对应页面；列表显示当前学期的全部课程，往期课程只有打开过才会显示。
2. 打开侧边栏的设置页，选择倍速、后台模式和静音选项；课件时长自动读取，无需填写。
3. 登录小雅后，在侧栏打开“视频课件”。
   可以逐项勾选，或用顶部“全选”勾选当前筛选中的可执行项目。切换筛选会保留已选项目。
   勾好后点“开始刷课”直接启动。设置页的同名按钮也使用当前已选项目。
   两处共用学习设置和运行状态。关闭侧边栏后队列继续，点击设置页的队列“停止”只停止刷课队列。
   默认开启“完成后自动打开下一个任务”：当前任务经平台确认完成后自动继续。
   关闭该开关则完成当前任务后暂停，保留当前页面。
4. 当前是可用于刷课的小雅课程页时沿用该页，否则在新标签页打开所选任务。队列在同一执行页顺序处理视频和课件。
   需保持 Chrome、该小雅标签页和电脑处于唤醒状态。可以切换到其他网页，小雅任务仍在原标签页后台运行。
   完成后在该小雅标签页内自动打开下一任务。
   任务进行中不要刷新、关闭或手动导航小雅页；在其他网页打开侧边栏也能点击队列“停止”。
   平台多标签页同时播放视频时是否累计有效计时尚未实测。
5. 如果浏览器阻止播放，请手动播放一次，或启用“静音自动播放”。

AI API 设置（A1）
在侧边栏设置中填写自己的 API 地址、密钥和模型，支持 Chat Completions 兼容服务。
地址支持 HTTPS 根地址、带版本的基础地址或完整 chat/completions 地址，以显示的实际请求地址为准。
本机服务可使用 http://localhost:端口/v1 或 http://127.0.0.1:端口/v1。
保存或测试时按所填域名请求访问权限，拒绝后不保存、不发送测试。
密钥仅本机保存且不回显，留空保留；更换实际请求地址需重新填密钥。
测试使用当前表单，只发送固定样题，不读取作业、不自动保存；可能产生少量 API 费用。
测试最多等待 25 秒，可取消，不自动重试；取消不保证服务商撤销已经收到的请求或计费。
删除配置会删除本机密钥，但不撤销浏览器已有的域名授权。

整份任务自动作答（B1）
重新加载扩展并重开侧栏后，类型筛选下方会出现选择数量和“自动作答并提交…”按钮。
勾选整份作业/练习/测验，检查完整清单并确认后，自动读取、补空题、交卷、核对结果。
已有人工答案保留；未选任务不动；只能提交一次的任务同样会执行。
附件题跳过，不调用 AI 或上传文件。其余支持的题目填写后保留原答题页，标记“待补附件”，整份留待手动提交。已有人工答案和附件保留。
待补附件计入本批已处理，批次结束后可以直接开始下一批。需要补附件时，可再回原答题页核对草稿。平台草稿的持久保存仍待实测。
非附件题不支持或失败时仍整份待处理；未知编辑器和图片/判断/组合题自动填写尚未适配。
运行中可点答题批次的“停止”；提交结果不明会暂停，不重复交卷。点“核对提交结果”读取平台最新状态；需保持小雅登录有效。
同一浏览器配置文件可同时运行一个视频课件队列和一个答题批次。刷课和答题各用自己的执行页，分别通过各自的“停止”按钮停止。后台重启不会自动恢复提交。
本地模拟整批验证通过，用户真实 Chrome 试用已有提交成功回执；并非所有课程和题型均已验收。最新附件策略与成功后切换耗时仍需重载后实测。

题旁 AI 浮标（A2）
保存配置后在小雅题目下方显示“AI 答案”；点击才查询，展示答案和简短解释，不填写、不提交。
支持单选、多选、填空逐空答案、判断、简答/论述/计算、附件题正文；组合题与图片输入已有模拟验证。判断/图片/材料组合题缺少真实样本，用户决定后补适配。
图片与文字共用 API 配置，需要用户选择支持图片输入的模型；公式可读取 LaTeX/MathML，或通过图片输入。图片读取失败不发送残缺题目。
附件题只展示可复制正文，不生成或上传文件；外部 PDF/Word 和音视频题干材料读取仍待适配。
每题可以填写“本题补充要求”，例如“100 字以内，分三点”；点击“重新生成”才再次请求。要求最多 2000 字符，只在本页本题保留。
查询全局单个请求、25 秒超时，可取消和手动重试；收起再展开不重复调用，切题和配置变更清除缓存。
更新后已有小雅页面需重新打开或刷新（先保存自己的草稿）。

视频与课件队列的行为与边界
- 只打开已选视频或课件。支持 MP4、WebM、M4V、MOV、PPT/PPTX、PDF 和 Word。
- 开始前核对选中任务的状态和身份。清单中的任务已完成、无法定位或状态有变化时，请刷新后重新选择。
- 进入具体任务后读取平台返回的完成状态；平台显示已完成时按完成项记录。
- 普通模式在视频实际播放至结尾后请求完成；课件通过平台完成按钮读取该任务的时长要求。
- 激进模式默认关闭。开启前会提示部分视频和文档任务可立即完成，通过此模式完成的任务不会增加相应的学习时长。该模式使用小雅页面的完成按钮，并按页面显示的完成状态更新队列。
- 平台若返回“已学习 17 秒，至少观看 2 分钟”，再等待剩余 103 秒；
  关闭“知道了”提示后继续计时，时间到后再次请求完成。
- 每份课件单独读取要求；若平台后续返回新的已学习时间或要求，重新计算剩余时间。
- 没有时间限制且平台直接确认完成的任务，立即进入下一项。
- 未返回可识别的时长要求时暂停提示，不采用默认秒数。
- 完成后只有检测到平台“已完成”，才打开下一项。普通模式的完成请求间隔至少 30 秒。
- 后台模式临时屏蔽页面的窗口失焦/隐藏事件，并提供前台可见状态，
  以减少前端切屏暂停；不修改播放位置、不伪造学习进度、不直接调用完成接口。
- 后台模式还处理 document.hasFocus 和兼容的 WebKit 可见性属性。
- 小雅页后台运行期间设置为不自动丢弃；停止、正常结束或启动失败后恢复原设置。
  这不能阻止浏览器崩溃、电脑睡眠或用户主动关闭页面。
- 服务端计时限制、浏览器节能/冻结、跨域播放器及后续平台改版可能影响运行。
  暂不保证所有课程在后台都能累计有效学习时间。
- 停止时恢复真实可见性并暂停视频；不会还原用户之前的倍速或静音设置。
- 页面出现验证码、登录失效、加载异常、无法切换时会暂停，需要手动处理。
- 队列仅在当前浏览器会话保存；退出 Chrome 后需要重新启动。
- 一个浏览器配置文件可并行运行一个视频课件队列和一个答题批次。它们使用不同标签页，可分别停止。

隐私
默认申请 whut.ai-augmented.com 站点权限、扩展本地存储、定时唤醒、侧边栏和页面脚本注入权限。AI 服务域名按保存或测试时填写的地址另外申请可选权限。
页面脚本注入用于检查并修复扩展重载后已打开页面尚未连接的问题，以及读取登录状态，仅限该小雅站点。
任务面板会读取小雅页面的登录凭据来请求任务数据，只发送给小雅站点，不写入本地存储；不读取或保存登录密码，任务列表请求仅发送给小雅；主动使用 AI 时按下文向所配置服务发送必要题目内容。
队列状态和最近 40 条日志保存在当前浏览器会话中，设置和任务缓存保存在扩展本地存储中。
AI 密钥保存在本机扩展 local 存储，不云同步、不额外加密，仅可信扩展上下文可读取，不交给小雅内容脚本或写入日志。
AI 连接测试发送固定测试题；浮标查询发送该题题干、选项、题型、所需图片及补充要求。后台使用配置的密钥和模型向所填服务请求，不发送人工答案，不携带小雅登录凭据或 Cookie，不跟随重定向。切换小雅账号不删除 AI 配置。

开发验证
在项目目录先运行 npm ci，再运行 npm test；安装浏览器扩展无需这些步骤。
AI 设置已通过模拟请求测试与 Chrome 本地窄屏预览；用户已在真实 Chrome 扩展配置个人服务并确认连接测试通过。长期存储行为、其他服务和 Edge 未全面验收。

从旧版本更新
结束运行中的批次并保存草稿，将新版 extension 文件夹更新到浏览器原来加载的路径。
在 Chrome 或 Edge 的扩展管理页找到“小雅刷课助手”，点击“重新加载”，再重开侧栏。
等作业编辑或提交结束后，再刷新或重开已有的答题页以使用新版浮标。
旧版保存的固定停留秒数不再生效。
