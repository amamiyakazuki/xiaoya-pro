# 小雅助手 Pro 0.7.2 功能改进说明：自动作答入口缓冲

**状态：已纳入 0.7.2 正式发布。**

在侧栏勾选测验并点击「自动作答并提交」后，扩展有时会停在预览页，提示「尚未进入可作答页面」。一种可能是：入口已经显示，但网页还没有绑定点击事件。此时即使能看见按钮，点下去也不会跳转。

## 拟调整的行为

| 何时等待 | 等待后做什么 |
| --- | --- |
| 预览页出现「点击进入任务>>>」 | 等约 **700 毫秒**，重新确认仍是本批次的同一任务、同一个入口，且入口可见、可用，再点击一次。 |
| Chrome 拦截新窗口，平台弹出「在当前页面跳转」 | 仅在识别到该弹窗时，再等约 **700 毫秒**；确认仍是原弹窗中唯一可用的跳转按钮，再点击一次。没有弹窗就不加这第二段等待。 |

如果用户在等待期间停止批次、切换了页面，或按钮被替换、隐藏、禁用，扩展不再点击。缓冲只用于上述两个导航入口，不改变「开始答题」、逐题填写、交卷或原有的全局超时，也不通过重复点击重试。

## 为什么先试 700 毫秒

在 Chrome 隔离样页中，使用相同的侧栏操作，刻意让网页在入口出现 **350 毫秒后**才绑定点击事件。原版在第 **8 毫秒**点击，没有跳转；候选版在第 **725 毫秒**点击，进入了后续查询阶段。两次都只点了一次，没有真实 AI 请求、填写或交卷。

这个对照说明短缓冲能缓解**点得太早**的情况；350 毫秒不是对真实平台加载速度的测量。700 毫秒也不能解除浏览器的新窗口拦截，或解决新标签已打开但扩展未能识别的问题。真实考试中这次超时的原因仍未确定。
